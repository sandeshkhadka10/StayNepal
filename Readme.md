# StayNepal

StayNepal aims to serve people by providing a web platform for various services and resources relevant to the Nepali community. Built using
HTML, CSS, Bootstrap, JavaScript, EJS, Node.js, Express.js and MongoDB, this project is structured to be easy to use, customizable, and ready for new contributors.

## Getting Started

These instructions will get your copy of StayNepal up and running on your local machine for development and testing purposes.

### Prerequisites

- [Node.js](https://nodejs.org/) (v12 or higher)
- [npm](https://www.npmjs.com/) package manager

---

## Setup Procedure

Follow these steps to set up and run the project:

1. **Clone the Repository**
   ```bash
   git clone https://github.com/sandeshkhadka10/StayNepal.git
   cd StayNepal
   ```

2. **Install Dependencies**
   ```bash
   npm install
   ```

3. **Configuration**
   - Create a `.env` file (if environment variables are required, see `.env.example` if available).
   - Fill in all necessary environment variables (e.g., database URLs, API keys).

4. **Run the Application**
   
   ```bash
   nodemon app.js
   ```

5. **Access the Application**
   - Open your browser and head to `http://localhost:3000` (default port; confirm with your app’s configuration).
